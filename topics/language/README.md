# Language (C++20/23)

Small programs, one theme each. CMake targets are named `cpp23_<basename>` (e.g. `cpp23_print`, `cpp23_spsc_ring_buffer`). `mdspan.cpp` is present but excluded from the build until the standard library provides `<mdspan>`.

See [../../GUIDE.md](../../GUIDE.md) (pillar index → Language).
